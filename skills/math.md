## Build understanding and fluency together

Learn what the objects mean, how to work with them, and when a technique applies. For example, understanding equality helps you justify applying the same operation to both sides of an equation. Solving and checking equations gives you more examples of how that principle works. Use diagrams, symbols, and verbal explanations when they reveal a relationship you need to understand. [Rittle-Johnson et al., concepts and procedures](https://doi.org/10.1037/0022-0663.93.2.346)

## Example progression for introductory algebra

1. **Study a correct model.** In `3(x − 2) = 12`, dividing both sides by 3 gives `x − 2 = 4`. Adding 2 gives `x = 6`. Substitution into the original verifies the result. Explain why each operation preserves the solution.
2. **Complete the missing step.** Start with `4(x − 1) = 20`. Fill the line between the original and `x = 6`, then check by substitution.
3. **Solve a parallel problem independently.** Try `2(x + 3) = 18`. Explain each step and verify the answer.
4. **Compare approaches.** For the original example, compare dividing first with distributing first. Both work. Identify how the structure makes one shorter.
5. **Mix familiar types after initial practice.** Try problems such as `2x + 5 = 13`, `−2x + 5 > 13`, and `2(x + 5)` with instructions to solve the first two and simplify the third. Write what the symbol and task tell you about the response. Use unlabeled examples and mix their order in later sessions.
6. **Change the representation.** A taxi charges a $5 base fare plus $2 per mile. How many miles can you travel for $13? Form the equation yourself and check that the answer fits the situation.

## Use errors to select practice

| Error | Next exercise |
| --- | --- |
| Missing prerequisite | Review the specific operation, notation, or concept with a short example |
| Incorrect setup | Translate between words, a diagram or table, and the mathematical expression |
| Wrong method | Compare a pair of similar-looking tasks and name the cue that distinguishes them |
| Invalid step | Explain the condition that makes it valid, then construct an example where it fails |
| Arithmetic or copying error | Work a few focused examples and add substitution, estimation, or another check |
| Correct result with weak explanation | Compare a second solution, justify a step, or explain what the answer means |

For proofs, study the structure of a model proof, name where each hypothesis is used, and reconstruct the argument. Then try a new statement, including a case where a changed hypothesis calls for a counterexample.

## Check retention and transfer

Re-solve a similar problem after a gap before consulting notes. Then try an unlabeled problem that uses a new representation or changes a condition. Score setup, method choice, execution, and explanation separately when possible. Use retrieval prompts to keep definitions and prerequisite facts available, and use actual problems to train and assess application.

## What the research covers

Math-specific meta-analyses support worked examples and distributed practice. Direct math studies comparing testing with restudy were few and had an inconclusive pooled result. A preregistered seventh-grade classroom experiment found better performance after interleaving on a study-specific delayed test. The interleaved assignments also naturally spaced similar problems. A separate experiment found that comparing two equation-solving methods helped procedural flexibility. [Barbieri et al., worked examples](https://doi.org/10.1007/s10648-023-09745-1) · [Murray et al., math spacing and retrieval](https://doi.org/10.1007/s10648-025-10035-1) · [Rohrer et al., interleaving experiment](https://uweb.cas.usf.edu/~drohrer/pdfs/Rohrer_et_al_2020JEdPsych.pdf) · [Rittle-Johnson and Star, strategy comparison](https://doi.org/10.1037/0022-0663.99.3.561)
