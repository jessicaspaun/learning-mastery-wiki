# Learning and mastery wiki

Start with something you want to be able to do. A useful plan for remembering guitar chord names looks a lot like a plan for remembering math definitions. A plan for playing in time with a band, proving a theorem, or choosing a pass under pressure needs practice that recreates the demands of that performance.

## Start here

1. **Define success.** Name the task, the conditions, and the standard. For example, “Play this song from start to finish with a steady pulse and recover after a missed chord.”
2. **Take a baseline.** Try one short version of the task independently. Notice where performance breaks down.
3. **Practice the bottleneck.** Recall missing information, study a model, rehearse a movement, compare problem types, or practice making the relevant decision.
4. **Get feedback and retry.** Use an answer key, tests, a recording, a reader, or a coach. Change one thing and see what happens.
5. **Come back later and vary the task.** Check whether you can still perform independently, then try a new example or a setting closer to your goal.

This is a practice design synthesized from research on memory, skill acquisition, feedback, and transfer. The domain guides show how to adapt each step. [How People Learn II](https://www.nationalacademies.org/read/24783/chapter/7) · [Learning versus performance](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/11/soderstorm_ra_learningvsperformance.pdf) · [Educational feedback meta-analysis](https://doi.org/10.3389/fpsyg.2019.03087)

| If you want to learn… | Spend most practice time on… | Check progress by… |
| --- | --- | --- |
